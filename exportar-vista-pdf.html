Exportar archivos HTML guardados a PDF

Selecciona uno o varios archivos HTML guardados que contengan páginas como imágenes de canvas. Los archivos se procesan localmente.

Para crear el PDF, el navegador abrirá el diálogo de impresión: elige «Guardar como PDF». La opción «Todos juntos» crea un PDF combinado; para tener un PDF por archivo, selecciona cada archivo en «Contenido» y repite la exportación.
