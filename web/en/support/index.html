Frequently asked questions

Is it free?

Yes, FullPage Saver is completely free, with no sign-up or artificial limits.

Does it send my pages to a server?

No. Everything is processed in your browser and saved to your computer through the download you confirm. There are no servers of its own and no analytics.

What permissions does it ask for, and why?

activeTab and scripting to read and scroll the tab when you press a button, downloads to save the file and pageCapture for the .mht format. Access to all sites is optional and only requested with a button, to embed resources from other domains.

The PDF has blank parts or missing pages

Set the capture speed to “Slow” and don't switch tabs while it captures. The automatic re-check captures again anything that hadn't finished loading.

Does it work with Gmail, Drive or PDF viewers?

Yes: app mode scrolls only the main panel of apps like Gmail, Drive or Outlook, and in PDF viewers it copies each page at its original size with its text.

Which languages is it available in?

Español, català, English, français, português, Deutsch and italiano. You choose the language the first time you open it.

The file downloads with a strange name (like “cb5d5c0d-….pdf”)

This usually happens when another extension interferes with downloads (download managers, antivirus…): Chrome ignores the name FullPage Saver requests. Try disabling that extension or rename the file.

Images or styles don't show in the saved HTML

When saving to HTML the extension asks, with a button, for access to all sites to download resources from other domains. If you decline, those resources stay linked and need a connection. Save again and accept the permission.

I can't save a Chrome page (chrome://…) or the Web Store

Chrome doesn't allow extensions to read its internal pages or the store. It's a browser limitation.

How do I save only part of a page?

In the preview, tick or untick sections and parts. You can also use Content only or reading mode.

Where does what I save end up?

Chrome opens the “Save as” dialog so you choose the folder. The HTML to PDF converter in “one PDF per file” mode saves without asking into the FullPage Saver folder in Downloads.

How do I delete temporary data?

Use Delete temporary data inside the extension when you finish; the preview is kept in the extension's local storage and never leaves your computer.

Can I change the keyboard shortcut?

Yes, at chrome://extensions/shortcuts. By default, Alt+Shift+P saves the tab as a PDF.

How do I update if I installed it manually?

Download the ZIP from the latest Release, replace the folder and click reload in chrome://extensions. From the Chrome Web Store it updates itself.
